# Clases de Programación

## Descripción del Curso

Este repositorio contiene el material de apoyo para el ramo de **Programación**.

## Estructura del Repositorio

El repositorio está organizado por módulos, donde cada módulo contiene carpetas organizadas por año y semestre de estudio.

## Contenido por Módulo

### Módulo 1 - Fundamentos de Programación
- **Duración:** 3 semanas
- **Contenidos principales:**
  - Concepto de algoritmo y trascendencia del curso
  - Modelamiento e implementación de algoritmos con Scratch
  - Entrada y salida de datos
  - Operadores aritméticos, lógicos y de comparación
  - Identificadores y variables
  - Introducción al lenguaje Python
  - Sentencias y expresiones
  - Generación de números pseudo-aleatorios

### Módulo 2 - Control de Flujo y Estructuras Básicas
- **Duración:** 3 semanas
- **Contenidos principales:**
  - Control de flujo: decisión (`if`, `else`)
  - Control de flujo: iteración (`while`)
  - Strings: concatenación, composición con formato, métodos
  - Listas: creación, acceso, recorrido por índices, porciones, índices negativos

### Módulo 3 - Funciones y Estructuras Avanzadas
- **Duración:** 3 semanas
- **Contenidos principales:**
  - Funciones: definición e invocación
  - Paso de parámetros y valores de retorno
  - Tipos por valor y por referencia
  - Módulos: importación y empaquetamiento
  - Listas anidadas: definición, creación dinámica, acceso y recorrido (`for`)

### Módulo 4 - Herramientas Avanzadas
- **Duración:** 3 semanas
- **Contenidos principales:**
  - Acceso a archivos
  - Diccionarios y tuplas
  - Introducción a NumPy
  - Gráficos 2D
  - Algoritmos recursivos: definición, estructura y algoritmos conocidos

---

**Nota:** Los resúmenes y material adicional de cada módulo se entregarán de forma presencial durante las clases.
